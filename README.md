# 🎯 Random Quote Generator

A web application that displays random inspirational quotes with a clean, modern interface.

## ✨ Features

- **Random Quote Generation** - Get new inspirational quotes with a single click
- **Responsive Design** - Works on all devices and screen sizes
- **Clean UI** - Modern and visually appealing interface
- **Easy to Use** - Simple one-click functionality

## 🛠️ Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Styling and responsive design
- **JavaScript** - Quote generation logic
